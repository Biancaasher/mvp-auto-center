# Checklist de Qualidade do Front-End - SA05

1. **Mensagens de validação mais claras:** Aplicadas no arquivo `js/script.js` para orientar o usuário.
2. **Feedback visual de erro/sucesso:** Aplicado nos inputs via JS alterando dinamicamente a cor da borda para vermelho.
3. **Padronização de layout:** Travamento das margens e espaçamentos internos (paddings) no arquivo CSS global.
4. **Refatoração leve:** Eliminação de variáveis e códigos mortos no escopo do manipulador de eventos.
