# Registro de Decisões Técnicas e Padrões - SA05

## 1. Padrão de Nomes
* Arquivos: Caixa baixa sem espaços, utilizando hífen se necessário.
* Funções JavaScript: Escritas em camelCase (ex: `buscarDados`).

## 2. Padrão Visual Mínimo
* Alinhamento de tabelas e formulários centralizados com padding padrão de 20px.
* Cores de Alerta: Borda vermelha para erros nos inputs e texto verde para sucesso.

## 3. Padrão de Validações
* Mensagem fixa abaixo do formulário indicando qual campo obrigatório está faltando.
