# MVP Auto Center - Gestão de Veículos

Sistema de controle de entrada e manutenção de veículos desenvolvido como projeto prático para a unidade curricular de Desenvolvimento de Sistemas.

 Objetivo do Protótipo
O objetivo deste protótipo é simular o fluxo operacional de entrada e listagem de veículos para uma oficina mecânica, garantindo uma interface simples e validações de dados seguras no Front-End.

Como Executar/Abrir o Projeto
1. Realize o download ou clone deste repositório.
2. Navegue até a pasta raiz do projeto.
3. Dê um duplo clique no arquivo `index.html` para abri-lo diretamente em qualquer navegador web (Google Chrome, Edge, Firefox), ou utilize a extensão *Live Server* no VS Code.

 Funcionalidades Entregues
* **Navegação Completa:** Links funcionais entre a Tela Inicial, Cadastro e Listagem.
* **Validação de Formulário:** Bloqueio de envios vazios com alertas claros e feedback visual com bordas vermelhas.
* **Mecanismo de Busca/Filtro:** Filtragem de veículos em tempo real na tela de listagem.
