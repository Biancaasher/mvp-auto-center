# Checklist - Auto Center

1. Organização e Separação de Pastas (/css, /js, /docs).
2. Nomes de arquivos consistentes em letras minúsculas.
3. HTML5 Semântico com tags estruturais (<header>, <nav>, <main>).
4. Código CSS unificado para evitar repetições (padrão DRY).
5. Funções JavaScript limpas com nomes claros e objetivos.
6. Versionamento rastreável vinculado ao quadro de tarefas do Trello.
